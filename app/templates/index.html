About This Tool

This tool helps you prepare research papers for a Retrieval-Augmented Generation (RAG) pipeline by:

  • Extracting text from PDF files
  • Using GPT-4o-mini to identify paper metadata (title, authors, abstract, etc.)
  • Chunking content into appropriate segments
  • Generating embeddings using OpenAI's embedding model
  • Storing both text and embeddings in MongoDB Atlas for later retrieval

Perfect for researchers, students, and developers working with academic content!
